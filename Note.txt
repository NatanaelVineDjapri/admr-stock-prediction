==============================
CATATAN/NOTE Project
=============================

1. Target definition:
    Target A: klasifikasi arah (naik/turun) besok
    Target B: regresi OHLC besok (atau % change OHLC)


2. Data collection:
    OHLCV historis ADMR
    Data makro (kurs, harga coking coal, IHSG)
    Data broker summary / foreign flow (kalau available)


3. Feature engineering:
    Technical indicators dari OHLCV
    Broker net buy/sell (rolling 3-5 hari)
    Foreign flow ratio


4. Modeling:
    Model klasifikasi terpisah dari model regresi (biasanya lebih clean daripada dipaksa jadi satu model)
    Bandingkan dengan/tanpa fitur broker buat lihat seberapa besar dampaknya


5. Evaluation:
    Klasifikasi: accuracy, precision/recall, confusion matrix
    Regresi: RMSE per OHLC component
    Feature importance: cek apakah fitur broker beneran nambah predictive power atau nggak
